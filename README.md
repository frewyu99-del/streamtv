# StreamTV — каркас приложения для Android TV / телефонов

- Android 6.0+ (minSdk 23), targetSdk 34
- Управление пультом (D-pad), значок в лаунчере Android TV (leanback) и на телефонах
- Экраны: Главная (ряды карточек), Поиск, Избранное/Профиль/Настройки (заглушки), Плеер (Media3 / HLS / MP4)
- Экран ошибки с кнопкой «Повторить»

## Сборка
1. Установите Android Studio (Koala или новее), откройте папку проекта.
2. Дождитесь синхронизации Gradle.
3. Build → Build APK(s) — готовый APK появится в app/build/outputs/apk/.

## Свой каталог
В app/build.gradle.kts замените API_URL на адрес вашего JSON:
{"rows":[{"title":"Новинки","items":[{"id":"1","title":"Название","poster":"https://…/p.jpg","stream":"https://…/video.m3u8"}]}]}
Пустой API_URL = демо-данные с публичными тестовыми видео.

## Важно для Android 6
В Android 6 нет корневого сертификата ISRG Root X1 (Let's Encrypt). Если ваш сервер использует такой сертификат и на старых приставках будет ошибка SSL — используйте сертификат другого центра или цепочку с кросс-подписью.

## Получить APK без Android Studio (GitHub)
1. Создайте бесплатный аккаунт на github.com → New repository (Private).
2. Загрузите в него все файлы проекта (Add file → Upload files; папку .github тоже).
3. Откройте вкладку Actions → дождитесь зелёной галочки (≈5 минут).
4. Откройте завершённый запуск → внизу «Artifacts» → скачайте StreamTV-apk.zip → внутри app-debug.apk.

## Установка на приставку
- Включите «Установка из неизвестных источников» в настройках приставки.
- Скопируйте app-debug.apk на флешку и откройте файловым менеджером приставки, либо через приложение «Send Files to TV», либо: adb connect IP_ПРИСТАВКИ && adb install app-debug.apk
